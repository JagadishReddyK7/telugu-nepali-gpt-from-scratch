# Attention example — telugu_nopos

Heatmap axes are labelled with token **positions**; this table maps
each position to its token. Matplotlib ships no Telugu or Devanagari
glyphs, so token strings cannot be drawn on the figure axes.

## Example passage (held-out test split)

> . 10 నెలల పాపను తన చీరకు కట్టుకొని నడుస్తుండగా వెనుక నుంచి వచ్చి చీరను కట్ చేసి తీసుకొని దొంగలు వెళ్లారు. ఓ కుటుంబం చీకటి కావడంలో బస్ స్టేషన్‌లో 18 నెలల బాబుతో కలిసి నిద్రకు ఉపక్రమించింది. ఇంతలోనే దొంగలు 18 నెలల బాబును ఎత్తుకెళ్లారు. కుటుంబ లేచి చూసేసరకి బాబు కనపడకపోవడంతో పోలీస్ స్టేషన్‌లో ఫిర్యాదు చేశారు. ఆస్ట్రేలియా టూర్‌లో సంచలన బ్యాటింగ్ ప్రదర్శన కనబర్చిన యువ హిట్టర్ రిషబ్ పంత్ .. ఇప్పుడు టీమిండియాలో న
